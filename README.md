## HUBSUS360

**Saúde pública · Challenge Oracle + FIAP**

> Em quais municípios de São Paulo as internações por condições sensíveis à atenção primária merecem investigação?

Essa pergunta guiou parte do **HUBSUS360**, projeto que desenvolvi em equipe. Cruzamos dados públicos de internações e estabelecimentos de saúde de São Paulo entre 2023 e 2025. Com Python e Pandas, preparamos as bases. No Oracle, organizamos os registros para comparar municípios, períodos e perfis de atendimento com SQL.
