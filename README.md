## HUBSUS360 · Análise das internações no SUS

Em quais municípios de São Paulo as internações por condições sensíveis à atenção primária merecem investigação? Essa foi uma das perguntas que exploramos no **HUBSUS360**, projeto que desenvolvi em equipe no Challenge Oracle + FIAP.

Cruzamos dados públicos de internações e estabelecimentos de saúde entre 2023 e 2025. Usamos **Python e Pandas** para preparar as bases e **SQL e Oracle** para organizar os registros e comparar municípios, períodos e perfis de atendimento. A [análise exploratória](https://github.com/Ladeira26/HUBSUS360/tree/main/aed) mostra como investigamos as diferenças entre os municípios.
